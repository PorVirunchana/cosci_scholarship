# COSCI Scholarship Web Application

A demo scholarship management web application developed as a final project for the **Application Program Development for Digital Business 1** course.

The project was designed to provide COSCI students with a centralized platform for viewing scholarship opportunities, checking scholarship records, and accessing student loan information.

## 👩🏻‍💻 Role

**Web Developer**

**Period:** December 2025

## 🔗 Live Demo

https://cosci-scholarship.onrender.com

> This project is a demo web application developed for educational purposes.

## ✨ Features

### 🔐 Student Login & Dashboard
- Student login system
- Personalized student dashboard
- Display student profile and academic information
- View scholarship history

### 🎓 Scholarship Listings
- Scholarship listings categorized into:
  - Faculty Scholarships
  - Internal Scholarships
  - External Scholarships
- Display scholarship information for students

### 📋 Scholarship Recipient Database
- Database-driven scholarship recipient list
- Retrieve and display recipient records from MySQL

### 💰 Student Loan (SLF)
- Student loan information
- Borrower statistics
- Loan status tracking
- Announcements
- Downloadable forms

## 🛠️ Technologies

- **Frontend:** HTML, CSS, Bootstrap
- **Backend / Database:** MySQL
- **Database Hosting:** Clever Cloud
- **Deployment:** Render

## 🚀 Deployment

The web application uses **MySQL** to store and retrieve student, scholarship, recipient, and student loan-related data.

The database is hosted on **Clever Cloud** and connected to the deployed web application on **Render**.

**Live Application:**  
https://cosci-scholarship.onrender.com

## 🎯 Project Objectives

- Apply web development concepts to a real-world educational service scenario
- Practice connecting a web application with a relational database
- Develop database-driven pages for managing and displaying student-related information
- Gain hands-on experience deploying a web application to cloud platforms
